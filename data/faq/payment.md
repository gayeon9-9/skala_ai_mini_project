# 결제가 처리 중이거나 완료 화면이 보이지 않을 때

결제 버튼을 누른 뒤 대기가 계속되거나 카드 승인 요청 뒤 완료 화면이 나타나지 않는 경우의 사용자 확인 안내입니다.

1. 중복 결제를 막기 위해 결제 버튼을 연속해서 누르지 않습니다. 주문 내역과 결제 내역에서 이미 처리되었는지 먼저 확인합니다.
2. 발생 시각, 주문 식별번호, 사용한 브라우저, 표시된 오류 문구를 기록합니다. 카드 번호 전체나 인증 정보를 문의에 적지 않습니다.
3. 승인 여부가 불명확하면 임의로 다시 결제하지 않고 담당자에게 확인을 요청합니다.
4. 시스템의 CPU 알림은 기초 점검 자료이며 실제 결제 승인·취소 결과를 뜻하지 않습니다. 실제 거래 상태는 별도 확인이 필요합니다.

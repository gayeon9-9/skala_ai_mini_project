# 페이지 접속 문제 확인

## 일반 접속 확인

업무 페이지가 열리지 않거나 다음 화면으로 이동하지 않는 경우의 일반 안내입니다. 특정 오류 코드가 표시되지 않아도 사용할 수 있습니다.

1. 문제가 생긴 페이지 주소와 발생 시각, 오류 문구를 기록합니다. 주소에 비밀번호나 인증 토큰이 있다면 제외합니다.
2. 사내 와이파이·유선망·VPN 등 사용 중인 연결 환경을 확인하고, 다른 업무 페이지도 열리지 않는지 살펴봅니다.
3. 잠시 후 한 번 다시 시도한 결과를 기록합니다. 회사의 보안 설정이나 방화벽을 임의로 끄지 않습니다.
4. 계속되면 영향받는 페이지와 사용 환경을 담당자에게 전달합니다. 페이지가 열리지 않는 증상만으로 특정 서버나 네트워크 장비의 고장을 확정하지 않습니다.

## HTTP 504 오류가 표시된 경우

이 절은 사용자가 HTTP 504 Gateway Timeout 오류 문구를 실제로 확인한 경우에만 적용합니다.

1. 오류가 표시된 페이지와 시각, 문구를 기록해 담당자에게 전달합니다.
2. 시간 초과 메시지만으로 네트워크 장비나 특정 서버가 고장 났다고 확정하지 않습니다. 실제 로그와 요청 경로는 담당자의 추가 확인이 필요합니다.

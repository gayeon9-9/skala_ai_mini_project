# 페이지 접속 실패와 504 시간 초과 확인

업무 페이지에 접속하지 못하거나 다른 서비스로 이동할 때 504 Gateway Timeout, 연결 시간 초과가 표시되는 경우의 사용자 안내입니다.

1. 문제가 생긴 페이지 주소와 발생 시각, 오류 문구를 기록합니다. 주소에 비밀번호나 인증 토큰이 있다면 제외합니다.
2. 사내 와이파이·유선망·VPN 등 사용 중인 연결 환경을 확인하고, 다른 업무 페이지도 열리지 않는지 살펴봅니다.
3. 잠시 후 한 번 다시 시도한 결과를 기록합니다. 회사의 보안 설정이나 방화벽을 임의로 끄지 않습니다.
4. 계속되면 영향받는 페이지와 사용 환경을 담당자에게 전달합니다. 시간 초과 메시지만으로 네트워크 장비나 특정 서버가 고장 났다고 확정하지 않습니다.
